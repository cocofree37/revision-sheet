# 夕凪掲示板

スレッドを立てて書き込める、シンプルな掲示板。単一の `index.html` で完結しています。

## 仕組み

投稿の保存・共有は claude.ai Artifact の `db` capability（`claude.use("db")`）を使っています。
そのため、投稿の保存が動くのは claude.ai 上で Artifact として開いたときだけです。
GitHub Pages など他のホストで開くと、画面は表示されますが読み書きはできません（案内メッセージが出ます）。

## 機能

- スレッド作成 / レス投稿 / `>>番号` の引用とジャンプ
- 同じ日は同じ人に同じ `ID:` を表示
- ライト・ダーク両対応、スマホ幅対応
