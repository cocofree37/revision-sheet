# 修正依頼シート

Webサイト制作の課題管理表。クライアントがサイトを見て「ここを直してほしい」を書き込み、制作チームが状態を管理します。
単一の `index.html` だけで動く静的ページなので、そのまま GitHub Pages で公開できます。

## 機能

- 修正依頼の登録（内容・対象ページ・詳細・分類・優先度・スクリーンショット）
- ステータス管理（未対応 / 対応中 / 確認待ち / 完了 / 保留）と絞り込み・検索
- 依頼ごとのコメント（やりとり）
- 立場の切り替え
  - クライアント：依頼の登録、コメント、「確認待ち」の依頼に対する完了／差し戻し
  - 制作チーム：状態・優先度・分類・担当の変更、依頼の削除
- 案件名・サイトURLの編集
- JSON の書き出し／読み込み、CSV の書き出し（Excel で開けます）

## データの保存について

現在の版は **データベースを使いません**。入力内容は、開いているブラウザの `localStorage` にだけ保存されます。

- 他の人とは共有されません（クライアントと制作チームが同じ表を見る、はできません）
- ブラウザのデータを消すと、内容も消えます
- 共有したいときは「JSONで書き出す」「CSVで書き出す」でファイルを渡してください
- 「立場」の切り替えは表示上のもので、認証ではありません

複数人で同じ表を見られるようにするには、`index.html` 内の「データ層（`store`）」をデータベース（Supabase など）に差し替えます。

## GitHub Pages で公開する

1. リポジトリを public にする（無料プランの場合）
2. Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にして Save
3. `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます

初回はサンプルの依頼が入っています。確認したら、ページ下部の「すべて消去」で空にして使い始めてください。
